## 1. 整体架构与角色分工

```
                    ┌───────────┐
                    │  制片人    │
                    │ (调度中心) │
                    └─────┬─────┘
            ┌─────────────┼─────────────┐
            ▼             ▼             ▼
      ┌───────────┐ ┌───────────┐ ┌───────────┐
      │   导演     │ │  服化道    │ │  分镜师    │
      │           │ │           │ │           │
      │ • 剧本分析 │ │ • 人物设定 │ │ • 动态提示 │
      │ • 剧情拆解 │ │   提示词   │ │   词编写   │
      │ • 讲戏     │ │ • 场景环境 │ │ • 静态分镜 │
      │ • 画风制定 │ │   提示词   │ │   提示词   │
      │ • 多重审核 │ │           │ │           │
      └───────────┘ └───────────┘ └───────────┘
```

### 1.1 角色定义

| 角色 | 职责 | 不做的事 |
|------|------|----------|
| **制片人** | 接收剧本，按阶段分发任务，收集各角色产出，组织审核流程，交付最终制作包 | 不直接创作任何提示词或内容 |
| **导演** | 剧本分析、剧情拆解、讲戏、画风制定、导演自审、服化道审核、分镜审核、合规审核 | 不编写具体提示词 |
| **服化道** | 人物设定提示词（三视图 + 表情）、场景环境提示词 | 不负责动态分镜 |
| **分镜师** | 动态视频提示词编写（Seedance 2.0）、静态场景分镜提示词（宫格模式） | 不负责人物/场景设计 |

### 1.2 执行顺序

```
剧本输入 → 制片人接收
  → 导演：剧本分析 + 剧情拆解 + 画风制定 + 讲戏
    → 服化道：人物设定提示词 + 场景环境提示词
      → 导演：服化道审核
        → 分镜师：动态提示词 + 静态分镜提示词
          → 导演：分镜审核 + 合规审核
            → 制片人：汇总交付
```

## 2. 制片人调度协议

### 2.1 制片人角色设定

制片人是整个工作流的调度中心，不参与任何具体创作。其核心职责：

1. **接收剧本** — 确认剧本完整性（角色、场景、对白、情绪线索）
2. **分阶段派发任务** — 严格按照执行顺序调度
3. **汇集审核结果** — 导演审核不通过时，退回对应角色修改
4. **交付制作包** — 最终产出包含：人物设定、场景设定、分镜表（静态+动态提示词）

### 2.2 调度流程

```
[阶段 1] 制片人 → 导演：请分析剧本并产出拆解文档
[阶段 2] 制片人 → 服化道：根据导演拆解产出人物和场景提示词
[阶段 3] 制片人 → 导演：请审核服化道产出
[阶段 4] 制片人 → 分镜师：根据审核通过的素材产出动态和静态提示词
[阶段 5] 制片人 → 导演：请审核分镜产出并做合规审核
[阶段 6] 制片人 → 汇总：产出最终制作包
```

> **审核退回规则：** 任何审核不通过，制片人退回到对应角色，附上导演的修改意见，修改后重新提交审核。最多退回 3 次，第 3 次退回时导演须给出可直接执行的具体修改方案。

## 3. 导演模块

> **角色定位：** 全世界最顶尖的导演，精通镜头语言、光影艺术、叙事节奏、构图法则。所有专业能力必须体现在产出中。

### 3.1 剧本分析

导演收到剧本后，产出以下分析文档：

#### 3.1.1 核心信息提取

| 分析项 | 说明 |
|--------|------|
| **故事主题** | 一句话概括核心主题与情感内核 |
| **情绪基调** | 整体情绪走向（如：温暖治愈、悬疑紧张、热血燃系） |
| **叙事结构** | 起承转合节点标注 |
| **角色关系图** | 主角、配角、关系线 |
| **时空设定** | 年代、地点、季节、时间段 |

#### 3.1.2 剧情拆解表

将剧本拆解为可执行的分镜单元：

| 场次 | 场景 | 角色 | 动作/事件 | 台词（如有） | 情绪 | 镜头构想 | 时长建议 |
|------|------|------|-----------|-------------|------|----------|----------|
| 1-1 | 城市天际线·黎明 | 无（空景） | 天际线渐亮 | — | 宁静·期待 | 大远景→缓推 | 5s |
| 1-2 | 公寓卧室 | 女主 | 闹钟响，翻身 | "又是新的一天…" | 慵懒·日常 | 中景→特写 | 5s |
| ... | ... | ... | ... | ... | ... | ... | ... |

> **关键要求：**
> - 第一个镜头必须是空景/建立镜头，交代环境与氛围
> - 最后一个镜头必须留有"呼吸感"——不能台词刚说完就结束，要有情绪延续（如角色沉默凝视、空镜回扫、渐黑等）
> - 空景镜头不少于总镜头数的 15%，用于节奏呼吸和情绪转换
> - 每个镜头必须注明时间段中发生的事（如"0-2s 天际线渐亮，2-4s 太阳露出地平线，4-5s 第一缕光线照射城市"）

### 3.2 画风制定

导演必须从市面上所有画风中为本剧挑选最适合的画风，并给出明确的画风定义。

#### 3.2.1 画风选型原则

1. **剧本匹配度** — 画风与故事情绪、题材、受众高度一致
2. **一致性可控** — 所选画风在 AI 生图/生视频工具中可稳定复现
3. **细节清晰度** — 画风必须支持面部细节、表情变化的清晰呈现

#### 3.2.2 画风参考分类

| 画风类别 | 适用题材示例 | 关键词特征 |
|----------|------------|-----------|
| **新海诚风** | 青春·恋爱·治愈 | 精细光影、通透色彩、大面积天空、光斑粒子效果 |
| **赛璐珞动漫风** | 热血·战斗·冒险 | 硬朗线条、高饱和色块、夸张动态 |
| **水墨国风** | 古装·武侠·仙侠 | 水墨晕染、留白、飘逸线条、东方意境 |
| **欧美漫画风** | 超英·科幻·奇幻 | 浓重阴影、肌肉线条、强对比 |
| **绘本风** | 儿童·童话·温馨 | 柔和色调、手绘质感、圆润造型 |
| **暗黑哥特风** | 恐怖·悬疑·暗黑 | 低明度、高对比、尖锐线条、不规则构图 |
| **3D 渲染写实风** | 科幻·都市·商业 | 高精度材质、物理正确光照、空间纵深 |
| **像素风/扁平风** | 复古·趣味·轻松 | 像素颗粒/矢量色块、几何化造型 |

#### 3.2.3 画风定义输出格式

```
画风名称：[名称]
画风关键词（中文）：[用于提示词的画风描述，如"新海诚风格，精细光影，通透色彩，动漫风格，光斑粒子效果"]
画风关键词（英文）：[Makoto Shinkai style, delicate lighting, translucent colors, anime style, light particle effects]
选择理由：[为什么这个画风最适合本剧本]
一致性锚点：[在所有提示词中必须出现的画风关键词子集，确保全片统一]
```

### 3.3 讲戏

导演对每个镜头给出专业的"讲戏"指导，供分镜师编写提示词时参考：

| 要素 | 说明 |
|------|------|
| **表演要求** | 角色的情绪状态、表情、肢体语言 |
| **镜头语言** | 景别、运镜、镜头速度、特殊技法（如希区柯克变焦、甩镜、一镜到底） |
| **构图法则** | 三分法、对角线构图、中心对称、框中框、前景遮挡等 |
| **光影设计** | 主光源方向、色温、光影比例、特殊光效（如逆光剪影、丁达尔光线、霓虹反射） |
| **空间结构** | 景深层次、前中后景安排、空间纵深引导线 |
| **节奏控制** | 镜头内部节奏（慢→快、静→动）、镜头间过渡方式 |
| **声画关系** | 台词与画面的配合、环境音暗示 |

### 3.4 导演审核体系

导演负责四个层级的审核：

#### 3.4.1 导演自审

在产出剧情拆解后，自查以下项目：

- [ ] 剧情逻辑是否连贯，是否有遗漏场景
- [ ] 情绪曲线是否自然，是否有突兀跳跃
- [ ] 镜头序列是否完整（开篇空景→正文→留白结尾）
- [ ] 每个镜头的时间段描述是否清晰
- [ ] 画风是否与剧本匹配

#### 3.4.2 服化道审核

- [ ] 人物设定是否符合剧本人设（年龄、性格、外貌、着装）
- [ ] 人物三视图是否完整（正面/侧面/背面 + 表情）
- [ ] 场景设定是否符合时空设定
- [ ] 人物/场景提示词画风是否与导演制定的画风一致
- [ ] 同一角色在不同场景中的描述锚点是否统一
- [ ] 提示词格式是否便于在 Nano banana 中使用

#### 3.4.3 分镜审核

- [ ] 动态提示词是否遵循 Seedance 2.0 官方规则
- [ ] 提示词格式：主体 + 动作/运动 + 镜头 + 光线 是否合并在一起（不分开）
- [ ] 第一个镜头到最后一个镜头是否串联
- [ ] 空景镜头是否充足（≥15%）
- [ ] 结尾镜头是否有呼吸感（不能台词刚说完就结束）
- [ ] 时间段描述是否清晰（哪个时间段发生什么事）
- [ ] 角色引用锚点（@图片N）是否一致
- [ ] 静态分镜提示词（宫格模式）是否完整
- [ ] 同一场景的局部分镜是否有对应静态提示词

#### 3.4.4 合规审核

- [ ] 内容是否存在违规风险（暴力、色情、敏感政治等）
- [ ] 台词是否有违规用语
- [ ] 画面描述是否可能触发平台审核
- [ ] 商业版权风险（参考的风格、角色是否有侵权嫌疑）

## 4. 服化道模块

> **角色定位：** 高品质服化道设计师，确保人物和场景的一致性、细节到位、提示词便于在 Nano banana 中产出使用。

### 4.1 人物设定提示词

#### 4.1.1 人物设定工作流

```
接收导演拆解文档
  → 提取角色列表与人设描述
    → 为每个角色编写三视图 + 表情提示词
      → 确保描述锚点统一（同一角色在所有提示词中的核心描述一致）
        → 提交导演审核
```

#### 4.1.2 人物提示词格式——三视图 + 表情

每个角色产出一段完整的提示词，用于在 Nano banana 中生成角色参考图。格式规范：

**布局结构：**

```
┌──────────────────────────────────────────┐
│  左侧：面部特写          右侧上半部分：  │
│  （详细五官特征）        正面 / 侧面 /   │
│                          背面全身视图     │
│                                          │
│                          右侧下半部分：  │
│                          4-6 个表情缩略图 │
└──────────────────────────────────────────┘
```

**提示词模板：**

```
Character reference sheet of [角色名], [画风关键词], [角色核心描述锚点（年龄/性别/体型/发型/发色/瞳色/肤色）].
Left: face close-up, [五官细节描述, 如 large expressive eyes with amber irises, small nose, gentle smile, light freckles across cheeks].
Right top: full-body front view / side view / back view, [服装完整描述, 如 wearing a white oversized hoodie, black pleated skirt, white sneakers, carrying a brown leather satchel].
Right bottom: 4-6 expression thumbnails showing [happy / sad / angry / surprised / shy / determined].
White background, highly detailed, detailed face, 8K, character reference sheet.
```

> **一致性要求：** 角色核心描述锚点（如"20岁，女性，中等身材，黑色齐肩短发，棕色瞳孔"）在该角色的所有提示词中必须完全一致，包括后续分镜师使用时。

#### 4.1.3 多套装处理

如果同一角色有多套服装（如日常装、制服、晚装），每套服装单独出一张参考图，共用相同的面部描述锚点。

### 4.2 场景环境提示词

#### 4.2.1 场景设定工作流

```
接收导演拆解文档
  → 提取场景列表与环境要求
    → 为每个场景编写场景环境提示词
      → 确保同一场景在不同镜头中的描述一致
        → 提交导演审核
```

#### 4.2.2 场景提示词格式

每个场景产出一段完整的提示词，用于在 Nano banana 中生成场景参考图。

**提示词模板：**

```
[画风关键词], [场景类型, 如 interior / exterior / cityscape],
[空间描述, 如 a cozy small apartment living room with warm wooden flooring],
[家具/道具, 如 a worn brown leather sofa facing a small TV, bookshelves lining the walls, a coffee table with scattered magazines],
[光照, 如 warm golden afternoon sunlight streaming through sheer curtains, casting long soft shadows],
[氛围, 如 lived-in, comfortable, slightly cluttered but homey],
[色调, 如 warm tones of brown, cream, and soft orange],
highly detailed, 8K, environment concept art.
```

#### 4.2.3 场景一致性锚点

与人物类似，每个场景也有"描述锚点"——在后续分镜中提到该场景时，必须使用相同的核心描述词。

**示例：**

```
场景锚点：
- "温馨小公寓客厅" → "cozy small apartment living room, warm wooden flooring, brown leather sofa, warm golden light"
- "雨后城市街道" → "wet urban street after rain, neon reflections on asphalt, glistening puddles, cool blue-purple tones"
```

### 4.3 服化道产出清单

最终交付：

- [ ] 每个角色的三视图 + 表情参考提示词
- [ ] 多套装角色的额外服装参考提示词
- [ ] 每个场景的环境参考提示词
- [ ] 角色描述锚点汇总表
- [ ] 场景描述锚点汇总表

## 5. 分镜师模块

> **角色定位：** 高品质分镜师，精通 Seedance 2.0 提示词规则，确保每个镜头有温度、有呼吸感，从第一个镜头到最后一个镜头完整串联。

### 5.1 分镜师工作流

```
接收导演拆解文档（含讲戏指导）
  + 接收服化道产出（角色参考 + 场景参考 + 锚点表）
    → 为每个镜头编写动态视频提示词（Seedance 2.0）
      + 为同一场景的局部分镜编写静态提示词（宫格模式）
        → 提交导演审核
```

### 5.2 动态视频提示词（Seedance 2.0）

#### 5.2.1 提示词核心规则

严格遵循 Seedance 2.0 官方规则，提示词公式：

```
[主体(@image引用)] + [动作/运动] + [镜头角度/运镜] + [光线/氛围] + [画风]
```

> **关键：主体、动作、运动、镜头、光线等要素合并在一段连续的描述中，不分开写。**

#### 5.2.2 提示词编写规范

**必须遵循的规则：**

1. **一体化描述** — 主体+动作+镜头+光影写在同一段话中，如：
   > "女主角(@图片1)在温馨小公寓客厅中慵懒地从沙发上坐起来伸了个懒腰，中景缓缓推近到面部特写，午后温暖的金色阳光透过薄纱窗帘在她脸上投下柔和的光斑，画面整体暖棕色调，新海诚风格精细光影"

2. **时间段明确** — 提示词中写明每个时间段发生什么：
   > "0-2s 城市天际线在晨曦中渐渐亮起，大远景，2-3s 镜头缓缓推近，第一缕阳光越过地平线照射在高楼玻璃幕墙上，3-5s 光线蔓延至整个城市天际线，画面被金色晨光浸染"

3. **@引用一致** — 使用 `@图片N` 引用角色参考图/场景参考图，同一角色在所有镜头中使用相同 `@图片N` 编号

4. **描述锚点统一** — 角色描述使用服化道提供的描述锚点文本，不得随意改动

5. **呼吸感** — 每个镜头留有情绪空间：
   - 开场必须有空景建立镜头
   - 角色说完台词后，镜头不立即切走，留 1-2 秒表情/动作余韵
   - 场景切换之间用空景/过渡镜头连接
   - 结尾镜头必须有延续感（角色凝视远方、空镜回扫、渐暗等）

6. **镜头串联** — 从第一个镜头到最后一个镜头要有完整的叙事弧线：
   - 镜头间有逻辑衔接（空间连续 or 时间连续 or 情绪连续）
   - 可使用"一镜到底""无缝转场""镜头平移过渡"等技法串联

7. **空景必备** — 空景镜头（无角色的纯场景/环境镜头）不少于总镜头数的 15%

8. **构图与空间** — 每个镜头注明构图法则和空间结构：
   - 对角线构图增加运动感
   - 中心构图突出主体
   - 三分法构图平衡画面
   - 框中框构图增强纵深
   - 前景遮挡增加层次

#### 5.2.3 动态提示词模板

```
镜头编号：S[场次]-[镜号]
时长：[N]s
类型：[空景 / 人物 / 对话 / 动作 / 过渡]
```

## 6. Seedance 2.0 规则集成规范

> 本节将 Seedance 2.0 官方规则与工作流深度集成，确保所有动态提示词产出严格合规。

### 6.1 提示词公式（必须遵守）

```
[主体(@image引用)] + [动作/运动] + [镜头角度/运镜] + [光线/氛围] + [画风]
```

**所有要素写在同一段连续文本中，不分行、不分点。**

### 6.2 @引用规范

| 引用类型 | 格式 | 用途 |
|---------|------|------|
| 角色面部 | `@图片N` | 保持角色面部一致性 |
| 角色服装 | `@图片N` | 脸部+服装分离策略 |
| 场景参考 | `@图片N` | 场景环境一致性 |
| 动作参考 | `@视频N` | 动作/运镜复刻 |
| 首帧图 | `@图片N` 标注为首帧 | 控制画面起始状态 |

### 6.3 一致性策略

参照 Seedance 2.0 官方规则"高级：实现一致性"章节：

1. **脸部 + 服装分离** — 面部和服装使用不同的 @图片 引用
2. **描述锚点统一** — 同一角色在所有镜头中使用完全一致的文字描述
3. **@image 编号固定** — 同一角色在全部镜头中使用相同的 @图片 编号

### 6.4 多模态参考

- 提示词中可同时使用 @图片 和 @视频 引用
- 写清楚哪个素材被用于什么目的：如"参考 @视频1 的运镜，角色面部来自 @图片1"
- 多素材时逐一标注，避免混淆

### 6.5 镜头串联与呼吸感规范

| 规则 | 具体要求 |
|------|----------|
| **开篇空景** | 第一个镜头必须是无角色的环境建立镜头 |
| **空景比例** | 空景镜头不少于总镜头数的 15% |
| **台词余韵** | 角色说完台词后镜头至少停留 1-2 秒，拍摄表情/反应 |
| **场景过渡** | 场景切换之间用空景或过渡镜头衔接 |
| **结尾留白** | 最后一个镜头必须是拉远/空镜/渐暗，留有情绪余韵 |
| **时间标注** | 每个镜头写明"0-Xs 发生什么, Xs-Ys 发生什么" |

### 6.6 提示词质量标准

- **不能太短** — 每个动态提示词至少 50 字（中文），确保信息充分
- **不能太长** — 每个动态提示词不超过 300 字（中文），避免模型混淆
- **一个镜头一个主要动作** — 不要在同一提示词中描述过多事件
- **风格统一** — 所有提示词末尾附加相同的画风关键词锚点
