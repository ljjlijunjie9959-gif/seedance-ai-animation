# seedance-ai-animation
AI-generated anime and short drama project using Seedance 2.0.

## AI漫剧短剧制作工作流

本项目包含一套完整的 **AI漫剧短剧制作工作流**，基于 Seedance 2.0 官方规则，融合顶级导演镜头语言与光影艺术。

📄 **[查看完整工作流文档](AI漫剧短剧制作工作流.md)**

### 工作流角色

- **制片人**：总调度，协调导演、服化道、分镜师三个核心角色
- **导演**：剧本分析、剧情拆解、讲戏、画风制定、多轮审核（自审/服化道审核/分镜审核/合规审核）
- **服化道**：角色设定提示词（含关键词锚点）、场景设定提示词（含宫格模式）
- **分镜师**：动态视频提示词编写，严格遵循 Seedance 2.0 规则

### 核心特性

- 所有提示词遵循 Seedance 2.0 公式：`[主体(@引用)] + [动作] + [镜头] + [光影] + [风格]`
- @人物、@场景、@镜头、@光影、@风格、@台词统一在同一条提示词中
- 角色「关键词锚点」跨场景复用，确保一致性
- 人物与场景自然融合（光照统一/投影互动/材质呼应/景深融入）
- 宫格模式生成场景多角度参考图
- 所有提示词可直接用于 Nano Banana 平台产出
