# seedance-ai-animation

AI 漫剧短剧制作工作流 — 基于 Seedance 2.0 + Nano banana

## 项目简介

本项目提供一套完整的 **AI 漫剧/短剧全流程制作工作流**，基于 Seedance 2.0 官方规则和全球顶尖导演的镜头语言设计。工作流采用四大角色协作模式：

| 角色 | 职责 |
|------|------|
| **制片人** | 全局调度，不直接创作，负责协调导演、服化道、分镜师三个角色 |
| **导演** | 剧本分析、剧情拆解、讲戏、画风制定、内容质量审核（自审+服化道审核+分镜审核+合规审核） |
| **服化道** | 角色设定提示词、场景设计提示词、人物-场景融合指引，支持宫格模式参考图 |
| **分镜师** | 动态视频提示词编写，遵循 Seedance 2.0 多模态语法规则 |

## 核心特性

- ✅ 完全遵循 **Seedance 2.0 官方规则**（提示词公式、@引用语法、多模态参考）
- ✅ 动态提示词在同一条中整合 @人物、@场景、@镜头、@光影、@风格、@台词
- ✅ 人物与场景**自然融合**（光照统一、色彩呼应、空间交互），杜绝图层感
- ✅ 角色和场景**一致性保障**（描述锚点机制 + 宫格参考图）
- ✅ 所有提示词**便于在 Nano banana 产出使用**
- ✅ 完整的导演审核体系（自审→服化道审核→分镜审核→合规审核）
- ✅ 包含从剧本到分镜的**完整示例**

## 快速开始

1. 阅读 [AI漫剧短剧制作工作流.md](AI漫剧短剧制作工作流.md)
2. 准备你的剧本文本
3. 按照工作流的 **使用说明** 章节，依次完成制片人→导演→服化道→分镜师的全流程
4. 将产出的提示词分别用于 Nano banana（静态参考图）和 Seedance 2.0（动态视频）
